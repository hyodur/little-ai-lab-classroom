첫 시험 순서

두 종류 사진 각 3장 이상 → AI 가르치기 → 새 사진 시험 → 사진·AI·조건 블록 연결 → 내 앱 실행.

사진 3장은 작동을 시작하는 최소량입니다. 학습 효과나 정확도를 보장하는 기준이 아닙니다. 최대 각 30장, 원본은 320px 이내로 줄여 사용합니다.

AI가 하는 일과 아이가 정하는 일

미리 학습된 MobileNet으로 사진의 특징을 추출하고, 학생이 붙인 이름과 사진으로 별도의 2종 분류기를 실제 학습합니다. 조건과 안내는 학생이 정한 규칙으로 실행됩니다.

AI는 정한 두 종류 중 하나를 고릅니다. 다른 물건·재질·오염 상태·실제 분리배출 방법을 판정하는 도구가 아닙니다. 환경 안내는 선생님과 확인해 주세요.

저장과 사진 처리

사진 학습과 예측은 이 브라우저 안에서 실행됩니다. 사진을 서버로 보내지 않습니다. 사진 추가와 학습 완료 후 이 기기의 브라우저에 한 작품을 자동 저장합니다. ‘저장하기’로도 보관할 수 있고, ‘수정용 받기(JSON)’는 사진·모델·블록이 들어 있는 수정용 파일을 받습니다. ‘내 앱 실행하기’의 ‘완성 앱 받기(HTML)’는 원본 학습 사진 없이 학습한 AI와 안내가 들어 있는 실행 파일을 받습니다. 다른 기기로 옮길 때는 파일을 열어 주세요.

브라우저 저장 자료는 정리·삭제될 수 있으니 수업 전후 파일로 보관해 주세요. 실제 갤럭시탭의 속도와 파일 복원은 수업 전에 확인해야 합니다.

선생님용 연습

물병·상자 그림을 자동으로 만들어 기능을 시험합니다. 실제 학생 사진으로 얻은 성능을 보여 주는 자료는 아닙니다. 현재 자료가 있으면 덮어쓰지 않습니다.
