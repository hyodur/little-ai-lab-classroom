# 꼬마 AI 개발 연구소 학생 실습용

초등학교 1학년 환경보호 AI 앱 만들기 5~8차시에 사용하는 두 종류 분류 앱입니다.
v0.6.2는 `play.html`에서 완성 HTML 파일을 읽고 웹 화면 안에서 촬영·시험하는 경로를 제공합니다. 종류 추가와 판단 보류 기능은 별도 확장판에서 개발합니다.

## GitHub Pages 배포

1. 기존 `hyodur/little-ai-lab-classroom` 저장소를 사용합니다.
2. 이 폴더의 내용물을 업로드합니다. `docs/index.html` 경로가 유지되어야 합니다.
3. 저장소 Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 설정합니다.
4. Branch는 main, Folder는 /docs를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Pages 화면에 표시되는 주소로 접속합니다. 학생에게는 그 주소의 QR을 제공합니다.

Pages 공개 배포를 마치면 학생은 ChatGPT나 GitHub에 로그인할 필요 없이 사용할 수 있습니다.
학생 작품과 사진은 저장소에 올리지 않습니다. 이 배포 묶음에는 앱과 공용 모델 파일만 들어 있습니다.

## 차시 운영

| 차시 | 학생 활동 | 마무리 |
|---|---|---|
| 5 | 두 종류 이름 정하기, 사진 모으기, AI 학습, 학습에 쓰지 않은 사진 시험 | 수정용 JSON 받기 |
| 6 | 저장 작품 이어 열기, 종이 설계를 블록으로 옮기기, 두 조건 연결 시험, 실제 사진으로 실행 | 수정용 JSON 받기 |
| 7 | 친구가 새 사진으로 시험, AI 판단과 안내 연결을 나누어 관찰, 자료나 블록 수정 후 재시험 | 수정 전후 기록, 필요하면 별도 확장판 선택 |
| 8 | 새로운 사진 최종 시험, 앱과 개발 과정 공유, 환경보호 실천 | 수정용 JSON과 완성 HTML 구분하여 보관 |

7차시까지 기본판으로 완성해도 됩니다. 종류 수는 우수 작품의 기준이 아닙니다.
확장판은 테스트 후 별도 주소로 제공합니다. 기존 작품의 확장판 가져오기는 아직 구현되지 않았습니다.

## 수업 전 실제 패드에서 확인

- 수업에 사용할 최종 주소와 동일한 브라우저로 접속합니다.
- 모둠별 기기를 정하고 5~8차시에 가능한 한 같은 기기와 브라우저를 사용합니다.
- 실제 사물 두 종류를 여러 방향과 배경으로 촬영하고 학습 시간과 새 사진 시험을 확인합니다.
- 사진 3장은 작동 최소 수량이며 정확도를 보장하지 않습니다. 사진 수보다 적합성과 다양성을 함께 살핍니다.
- 학습 후 새로고침해 사진·모델이 복원되는지 확인합니다.
- 수정용 JSON을 내려받아 다시 열어 사진·모델·블록이 유지되는지 확인합니다.
- 파일명은 내려받은 뒤 `1모둠-5차시.json`처럼 바꾸어 보관하면 찾기 쉽습니다.
- 첫 접속과 학습을 여러 패드에서 함께 실행해 기기 속도와 학교 네트워크를 확인합니다.
- 카메라가 열리지 않으면 사이트 권한을 확인하고 사진 넣기·사진첩 경로로 시도합니다.
- 완성 HTML은 기기의 파일 미리보기 방식에 따라 실행이 다를 수 있습니다. 5~7차시는 웹 주소 안에서 실습하며, 공유 파일은 실제 기기에서 먼저 확인합니다.

## 완성 HTML로 휴대폰에서 촬영하기

https://hyodur.github.io/little-ai-lab-classroom/play.html 에서 이미 받은 완성 HTML 파일을 고릅니다. 예전 완성 HTML도 지원하며 다시 학습할 필요가 없습니다. 카메라 권한은 이 웹사이트와 브라우저에 허용해야 합니다.

파일의 JSON 데이터만 읽으며 첨부 HTML의 스크립트나 문서는 실행하지 않습니다. 학습 값과 시험 사진을 서버로 보내거나 공개 저장소에 저장하지 않습니다. 화면을 새로 열면 파일을 다시 선택합니다. 파일을 직접 여는 환경이나 외부 카메라 앱의 반환 처리에 문제가 있을 때 이 경로를 사용합니다. 실제 학교 기기의 촬영과 권한은 별도 확인이 필요합니다.

`docs/play.html`의 공통 화면은 `node scripts/build-web-player.cjs`로 생성합니다.

## 저장과 주소 이동

자동 저장은 현재 기기·브라우저·사이트 주소의 한 작품에 적용됩니다. 같은 브라우저를 여러 모둠이 번갈아 쓰면 JSON으로 작품을 바꾸어 열어야 합니다.
ChatGPT 사이트에 저장한 작품이 GitHub 주소로 자동 이동하지는 않습니다. 기존 주소에서 수정용 JSON을 받고 새 주소에서 열어 옮깁니다.
사진과 모델을 포함하는 JSON은 수업 자료로 보관하고, 공개 GitHub 저장소에 올리지 않습니다.

## 기본판의 판단 범위

이 앱은 어떤 사진이든 학습한 두 종류 중 하나를 선택합니다. 낯선 물건을 자동으로 거절하는 기능은 없습니다.
두 종류 밖 물건을 시험했다면 그 한계를 관찰 내용으로 기록합니다. 앱의 환경 안내는 교사와 확인합니다.

카메라 자동 검사는 모의 장치를 포함하며 실제 갤럭시탭의 카메라·메모리·성능을 검증한 것은 아닙니다. 합성 사진 분류 성공은 교실 사진 정확도를 보장하지 않습니다.

검사 실행 예: `node tests/engine-test.cjs`
